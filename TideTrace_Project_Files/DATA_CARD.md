# TideTrace // Data Card
### Satellite Imagery & Vessel Telemetry Datasets

---

## 1. Remote Sensing SAR Data
- **Sensor:** Sentinel-1A / 1B C-Band SAR (5.405 GHz).
- **Acquisition Mode:** Interferometric Wide (IW) Ground Range Detected (GRD).
- **Polarization:** Dual-Pol (VV + VH).
- **Pixel Resolution:** 10m Ground Sample Distance (GSD).

---

## 2. Vessel Telemetry (AIS) Data
- **Message Types:** Class A & B Static/Dynamic Vessel Reports (NMEA-0183 / JSON).
- **Fields:** MMSI, IMO, Vessel Name, SOG, COG, Heading, Draft, Navigation Status.
